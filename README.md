# Last Ark releases

Last Ark is an offline survival app for Android: Wikipedia and other books, world maps with GPS and
place search, an AI assistant that runs on the phone, and a survival toolkit. Everything works with
no internet once downloaded.

## Install

1. Open the [latest release](https://github.com/mijsjohaniglesia/last-ark-releases/releases/latest) on your Android phone.
2. Download `LastArk-<version>.apk` and open it. Allow "Install unknown apps" when asked.

Requires Android 11 or newer on a 64-bit phone (8 GB RAM recommended for the AI assistant).

## Updates

Last Ark checks this page once a day on Wi-Fi and updates itself. The first update asks you to tap
"Update"; on Android 12 and newer later updates install silently. Your downloaded books, maps and
AI models are kept.
